1. Basics & Includes

Warm up with the building blocks. Every C++ program needs these.
Multiple Choice
1.1 Which include do you need at the top of your file to use cout?
1.2 What does endl do?
1.3 Which line goes at the very TOP of a C++ file?
1.4 Why do we write using namespace std; at the top?
Code Writing
1.5 Write a complete C++ program that prints exactly: Hello, my name is Travis

Solution

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, my name is Travis" << endl;
    return 0;
}
Explanation: Three things every program needs: the include for cout, the main function, and a return 0 at the end. The text inside cout goes in double quotes.
1.6 Write a program that declares an int age set to 25, and prints I am 25 years old using that variable.

Solution

#include <iostream>
using namespace std;

int main() {
    int age = 25;
    cout << "I am " << age << " years old" << endl;
    return 0;
}
Explanation: You can chain multiple things to cout with <<. Notice the spaces inside the quotes so the words don't run together.

2.6 Write a function called greet that takes a string name and prints "Hello, [name]!". The function returns nothing.

Solution

void greet(string name) {
    cout << "Hello, " << name << "!" << endl;
}
Explanation: Return type is void since the function only prints, it doesn't return anything. The exclamation mark goes inside its own pair of quotes after the name.

Solution

    string name;

};
Explanation: Don't forget the semicolon at the very end after the closing brace. Each field also needs its own semicolon.
3.6 Define a struct called Movie with three fields: a title (string), a release year (int), and a rating (double). Then in main, declare a Movie variable, set all three fields, and print them.

Solution

struct Movie {
    string title;
    int year;
    double rating;
};

int main() {
    Movie m;
    m.title = "Inception";
    m.year = 2010;
    m.rating = 8.8;
    cout << m.title << " (" << m.year << ") " << m.rating << endl;
    return 0;
}
Explanation: The struct goes above main. Inside main, declare a Movie variable with Movie m;, then use the dot operator to set each field one by one.

4. Vectors

A vector is a list that can grow and shrink as needed.
Multiple Choice
4.1 How do you add an element to the end of vector v?
4.2 How do you check how many elements are in vector v?
4.3 What does vector<int> nums; create?
4.4 Why do we pass a vector to a function with & like vector<int>& v?
Code Writing
4.5 Write code that creates a vector of ints, adds the numbers 5, 10, and 15 to it, then prints the size of the vector. (Just the code inside main is fine.)

Solution

vector<int> nums;
nums.push_back(5);
nums.push_back(10);
nums.push_back(15);
cout << nums.size() << endl;
Explanation: Declare an empty vector, push_back three values, then print the size. The output will be 3 since there are 3 elements.
4.6 Write a function called sumAll that takes a vector<int> and returns the total sum of all numbers in it.

Solution

int sumAll(vector<int> v) {
    int total = 0;
    for (int i = 0; i < v.size(); i++) {
        total += v[i];
    }
    return total;
}
Explanation: Start with total = 0, loop over every element using its index, and add each one to total. The shorthand total += v[i] is the same as total = total + v[i].

5.5 Write a for loop that prints the numbers 1 through 10, each on its own line.

Solution

for (int i = 1; i <= 10; i++) {
    cout << i << endl;
}
Explanation: Start at 1, keep going while i is less than or equal to 10. Using <= 10 is what includes 10 in the output.
5.6 Write a function countMatches that takes a vector<int> and an int target, and returns how many times target appears in the vector.

Solution

int countMatches(vector<int> v, int target) {
    int count = 0;
    for (int i = 0; i < v.size(); i++) {
        if (v[i] == target) count++;
    }
    return count;
}
Explanation: Start count at 0, loop over the vector, and increment count every time we find target. Use == for comparison, not = which is assignment.

6. Random Numbers

Use rand() to get random values, with a simple formula for ranges.

Code Writing
6.5 Write a single line that stores a random number from 1 to 100 in an int variable named r.

Solution

int r = rand() % 100 + 1;
Explanation: The formula is rand() % range + start. For 1 to 100, range is 100 and start is 1.
6.6 Write a function rollDice that takes an int n and returns a vector of n random dice rolls (each 1-6).

Solution

vector<int> rollDice(int n) {
    vector<int> rolls;
    for (int i = 0; i < n; i++) {
        rolls.push_back(rand() % 6 + 1);
    }
    return rolls;
}
Explanation: Make an empty vector, loop n times, push a random 1-6 each time, return the vector at the end.

7. Type Casting & Probability Math

Watch out for integer division, this is the #1 trap on this exam.
Multiple Choice

7.2 What does 7 / 2.0 equal?
7.3 If count is an int with value 50, what is the value of count / 100?
7.4 Which of these correctly calculates a probability when count is an int?
Code Writing
7.5 Given int hits = 17; and int total = 50;, write one line that stores the probability (as a decimal between 0 and 1) in a double variable named p.

Solution

double p = hits / (double)total;
Explanation: Casting total to double forces double division. You could also write (double)hits / total or, if total were a literal, hits / 50.0.
7.6 Write a function average that takes a vector<int> and returns the average value as a double.

Solution

double average(vector<int> v) {
    int total = 0;
    for (int i = 0; i < v.size(); i++) {
        total += v[i];
    }
    return total / (double)v.size();
}
Explanation: Sum everything first into an int, then divide by the size, but cast to double so we get a proper decimal answer instead of integer division.

8. File I/O

The hardest topic. Take your time with these.
Multiple Choice
8.1 Which include is needed for ifstream?
8.2 What does getline(fin, name, ',') do?
8.3 Why call fin.ignore() after reading numbers with fin >> x?
8.4 Which operator reads the next whitespace-separated token from a file stream?
Code Writing
8.5 Write code that opens a file data.txt and reads one int from it into a variable named x. (Just the few lines for opening and reading.)

Solution

ifstream fin("data.txt");
int x;
fin >> x;
Explanation: Open the file by passing the filename to ifstream. Declare an int. Use >> to extract the next whitespace-separated value into it.
8.6 Suppose you have a struct Person { string name; int age; };. Write a function loadPeople that takes a filename and a vector<Person>&. Each line of the file looks like "Alice, 25". Read every line into the vector.

Solution

void loadPeople(string filename, vector<Person>& people) {
    ifstream fin(filename);
    string name;
    int age;
    while (getline(fin, name, ',')) {
        fin >> age;
        fin.ignore();
        Person p;
        p.name = name;
        p.age = age;
        people.push_back(p);
    }
}
Explanation: getline with comma reads up to the comma into name. Then >> reads the int. fin.ignore() skips the newline before looping back. Build a Person struct, set fields, push to the vector. The & on the vector parameter is critical, without it the data goes into a copy and disappears.
