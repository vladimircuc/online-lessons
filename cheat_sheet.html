1 Program skeleton

#include <iostream>
using namespace std;

int main() {
    // code here
    return 0;
}
Every program needs int main() and return 0;

2 Which include do I need?

<iostream>cout, cin, endl
<fstream>ifstream (read files)
<vector>vector type
<string>string type
<cstdlib>rand, srand
<ctime>time

3 Output with cout

int age = 25;
cout << "I am " << age << " years old" << endl;
Chain as many << as you want. Use endl at the end for a new line.

4 Variable types

int count = 10;        // whole number
double rate = 0.47;    // decimal
string name = "Travis";
bool done = true;     // true or false

5 Functions, basic shape

return_type name(type param) {
    return something;
}

// Examples:
int add(int a, int b) { return a + b; }
void greet(string n) { cout << n; }
void means returns nothing. Use it for print functions.

6 Pass by reference (&)

// Without &, function gets a copy:
void fill(vector<int> v) { ... }

// With &, modifies the original:
void fill(vector<int>& v) { ... }
Always use & when passing a vector you want to modify, like in the load function.

7 Define a struct

struct Trip {
    string city;
    int leave;
    int back;
};   // don't forget the ;
The semicolon after the closing brace is required. Forgetting it is the #1 struct bug.

8 Use a struct

Trip t;
t.city = "Denver";
t.leave = 100;
t.back = 110;
cout << t.city << endl;
Dot operator (.) reads and writes struct fields.

9 Vectors, basics

vector<int> nums;       // empty
nums.push_back(10);     // add to end
nums.push_back(20);

cout << nums[0];        // 10
cout << nums.size();    // 2

10 Vector of structs

vector<Trip> trips;
Trip t;
t.city = "Paris";
t.leave = 50;
t.back = 60;
trips.push_back(t);

cout << trips[0].city;  // Paris

11 For loop

for (int i = 0; i < 10; i++) {
    cout << i << endl;
}
Use when you know how many times.

12 While loop

int size = 2;
while (trial(size) <= 0.5) {
    size++;
}
Use when you don't know the count yet.

13 Loop over vector

for (int i = 0; i < v.size(); i++) {
    cout << v[i] << endl;
}

14 Nested loop, every pair

for (int i = 0; i < v.size(); i++) {
    for (int j = i + 1; j < v.size(); j++) {
        if (v[i] == v[j]) return true;
    }
}
return false;
j = i + 1, NOT j = 0. Otherwise you compare items to themselves.

15 State tracking in a loop

int last = 0;   // declare BEFORE the loop
for (int i = 0; i < trips.size(); i++) {
    if (trips[i].leave > last) {
        print(trips[i]);
        last = trips[i].back;   // update
    }
}
Pattern: declare a tracker variable above the loop, update it inside.

16 Random numbers

// In main, once:
srand(time(0));

// To get random 1 to N:
int x = rand() % N + 1;

// Examples:
rand() % 6 + 1      // dice roll, 1 to 6
rand() % 365 + 1    // day, 1 to 365
rand() % 100 + 1    // 1 to 100
srand goes ONCE at the top of main, never inside a loop or function.

17 Integer division TRAP

int count = 47;
double p = count / 100;     // 0 (WRONG)
double p = count / 100.0;   // 0.47 (CORRECT)

// When dividing two int variables:
double avg = total / (double)v.size();
int / int = int, decimals get thrown away. Always put a .0 or cast to double when computing probabilities.

18 File I/O, reading from a file

The hardest topic on the exam. This is the exact pattern for reading "name, num num" lines.
#include <fstream>

void load(string filename, vector<Trip>& trips) {
    ifstream fin(filename);              // open file
    string city;
    int leave, back;
    while (getline(fin, city, ',')) {     // read up to comma
        fin >> leave >> back;             // read the two numbers
        fin.ignore();                     // skip leftover newline
        Trip t;
        t.city = city;
        t.leave = leave;
        t.back = back;
        trips.push_back(t);
    }
}
Three rules for mixed reading: getline with comma for the string part, >> for the numbers, fin.ignore() after the numbers so the next getline starts on a fresh line.

Final exam checklist

  1. Includes at the top. iostream, fstream, vector, string, cstdlib, ctime as needed. Add using namespace std;
  2. Semicolon after every struct. struct Trip { ... };
  3. Vector parameters get an & when the function modifies them.
  4. Nested loops use j = i + 1 for the inner loop, never j = 0.
  5. Divide by 100.0, not 100 when calculating a probability.
  6. srand(time(0)) goes once at the top of main, never inside loops or other functions.
  7. File reading order: getline (string with comma), then >> (numbers), then fin.ignore().
  8. return 0; at the end of main.
