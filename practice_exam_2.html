Program 1, Conference Room Bookings (Parts 1-5)

A program for managing conference room bookings. The room can only host one meeting at a time.

PART 1

Define a struct called Booking

Define a struct called Booking that contains:
  • the name of the team
  • a number 1-24 for the start hour of the meeting
  • a number 1-24 for the end hour of the meeting

Solution

struct Booking {
    string team;
    int start;
    int end;
};

Explanation

Three fields, one string and two ints. Don't forget the semicolon after the closing brace, it's the most common mistake. Field names can be anything, but they should be readable like start and end.
PART 2

Function to read bookings from a file

Function name load. Parameters: filename and a vector of Bookings. Each line is: team name, comma, then 2 numbers. Build a Booking struct for each line and add it to the vector.
Example rooms.txt Marketing, 9 11
Sales Team, 10 12
Engineering, 13 15
Design Group, 14 16
HR, 16 17

Solution

void load(string filename, vector<Booking>& bookings) {
    ifstream fin(filename);
    string team;
    int start, end;
    while (getline(fin, team, ',')) {
        fin >> start >> end;
        fin.ignore();  // skip the newline before next getline
        Booking b;
        b.team = team;
        b.start = start;
        b.end = end;
        bookings.push_back(b);
    }
}

Explanation

The vector parameter MUST have the & so we modify the original. getline(fin, team, ',') reads everything up to the comma into team. Then fin >> start >> end grabs the two numbers (the leading space after the comma is automatically skipped by >>). fin.ignore() swallows the leftover newline so the next getline starts cleanly on the next line.
Common bug: Forgetting the & on the vector parameter. Code compiles and runs, but the bookings vector is empty back in main.
PART 3

Function to print one booking

Function name print. One parameter: a Booking. Print like "Marketing 9-11".

Solution

void print(Booking b) {
    cout << b.team << " " << b.start << "-" << b.end << endl;
}

Explanation

Use the dot operator to access struct fields. The format is team name, space, start hour, hyphen, end hour. Return type is void because we just print, we don't return anything.
PART 4

Function to print non-conflicting bookings

Function name schedule. Parameter: vector of Bookings. Print bookings, but skip any that start before or at the same hour the previously printed booking ended. The bookings are already sorted by start hour.
Expected output for the example file Marketing 9-11
Engineering 13-15
HR 16-17

Solution

void schedule(vector<Booking>& bookings) {
    int lastEnd = 0;
    for (int i = 0; i < bookings.size(); i++) {
        if (bookings[i].start > lastEnd) {
            print(bookings[i]);
            lastEnd = bookings[i].end;
        }
    }
}

Explanation

Track the end hour of the last booking we printed. For each booking in the vector, only print it if its start hour is strictly greater than that. After printing, update lastEnd. Initializing to 0 means the very first booking always prints (since all start hours are 1 or higher).
Watch the comparison: The problem says skip if start is "before or at the same hour" the previous ended. So we print only when start > lastEnd, not >=.
PART 5

Main program

Put it all together. Includes at top, call load with "rooms.txt", then call schedule.

Solution

#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

// struct Booking { ... };
// void load(...) { ... }
// void print(...) { ... }
// void schedule(...) { ... }

int main() {
    vector<Booking> bookings;
    load("rooms.txt", bookings);
    schedule(bookings);
    return 0;
}

Explanation

Four standard includes: iostream for cout, fstream for ifstream, vector and string for the data types. Declare an empty vector, fill it with load, print the schedule. return 0 at the end signals success.
Program 2, Random Survey ID Conflicts (Parts 6-9)

A program to find out how big a survey group needs to be before two participants probably get assigned the same random ID number (1 to 100).

PART 6

Function to generate random IDs

Function name makeIDs. Parameter: group size (number of IDs to make up). Put that many random ints (1-100) into a vector. Return the vector.

Solution

vector<int> makeIDs(int size) {
    vector<int> ids;
    for (int i = 0; i < size; i++) {
        ids.push_back(rand() % 100 + 1);
    }
    return ids;
}

Explanation

rand() % 100 gives a number from 0 to 99. Adding 1 shifts it to 1-100 as required. Loop size times, push each random number, return the vector.
Setup matters: srand(time(0)) must be called once in main, otherwise rand() gives the same sequence every run. Need #include <cstdlib> for rand and #include <ctime> for time.
PART 7

Function to find duplicates

Function name conflict. Parameter: vector of ints. Compare every int to every other int. Return true if any two are the same, false otherwise.

Solution

bool conflict(vector<int> v) {
    for (int i = 0; i < v.size(); i++) {
        for (int j = i + 1; j < v.size(); j++) {
            if (v[i] == v[j]) return true;
        }
    }
    return false;
}

Explanation

Classic nested loop pattern for comparing every pair. Outer loop picks the first item, inner loop checks every later item. Starting j = i + 1 avoids comparing an item to itself and avoids checking the same pair twice. The moment we find a match, return true. If both loops finish, return false.
Don't write j = 0 in the inner loop, that compares every element to itself and gives a false positive on every call.
PART 8

Function to run 100 trials

Function name trial. Parameter: group size. Call makeIDs and conflict 100 times. Count how many times conflict returned true. Probability is count / 100. Print group size and probability. Return the probability.

Solution

double trial(int size) {
    int count = 0;
    for (int i = 0; i < 100; i++) {
        vector<int> ids = makeIDs(size);
        if (conflict(ids)) count++;
    }
    double prob = count / 100.0;
    cout << "size=" << size << " prob=" << prob << endl;
    return prob;
}

Explanation

Loop 100 times. Each iteration: get a fresh random vector, check for a conflict, increment count if found. Compute the probability as a double, print, return.
The biggest gotcha on this exam: count / 100 is integer division. If count is 47, you get 0, not 0.47. Use count / 100.0 (note the .0) to force double division.
PART 9

Main program: find smallest group with probable conflict

Don't forget the includes. Call trial(2), trial(3), etc. in a loop. Stop when the return value is greater than 0.5.

Solution

#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

// vector<int> makeIDs(int size) { ... }
// bool conflict(vector<int> v) { ... }
// double trial(int size) { ... }

int main() {
    srand(time(0));
    int size = 2;
    while (trial(size) <= 0.5) {
        size++;
    }
    return 0;
}

Explanation

srand(time(0)) seeds the random generator once at program start. The while loop calls trial(size), and as long as it returns 0.5 or less, we increment size and try again. As soon as trial returns more than 0.5, the loop exits. Since the ID range is only 1-100 (smaller than the 1-365 birthdays), expect the threshold to hit much earlier, around size 12 or 13.
Don't put srand inside the loop. Seed once, at the top of main. Seeding repeatedly with the same time value resets the sequence.
