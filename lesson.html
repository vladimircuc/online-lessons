1. Basics & Includes

Every C++ program starts with the same skeleton. Get this fluent and the rest gets easier.

The skeleton

Every program needs int main(). Above it go the #include lines for any libraries you use, plus using namespace std; so you can write cout instead of std::cout.

#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    return 0;
}

Which include do I need?

  • <iostream> for cout, cin, endl
  • <fstream> for ifstream (file reading)
  • <vector> for vector<T>
  • <string> for string
  • <cstdlib> for rand() and srand()
  • <ctime> for time()
Memory aid: if you see ifstream in your code, you need fstream. If you see vector, you need vector. If you see rand, you need cstdlib AND ctime (because you also need time for srand).

Output basics

cout << sends data to the screen. Chain multiple values with more <<. endl ends the line.

cout << "Score: " << score << " / " << total << endl;

2. Functions

A function is a named block of code with inputs (parameters) and an output (return value). Every problem on this exam asks you to write functions.

Anatomy of a function

return_type name(type param1, type param2) {
    // body
    return something;
}

If a function returns nothing, the return type is void and you skip the return statement.

Two examples

// Returns an int
int add(int a, int b) {
    return a + b;
}

// Returns nothing, just prints
void greet(string name) {
    cout << "Hi " << name << endl;
}

By value vs by reference

Normally a parameter is a copy of what was passed in. Changes to it inside the function don't affect the original. Add an & after the type and you're working with the original directly.

// By value, x outside is unchanged
void doubleIt(int x) { x = x * 2; }

// By reference, x outside IS changed
void doubleIt(int& x) { x = x * 2; }
When to use &: when you need the function to modify the variable, OR when the variable is big (like a vector) and copying it would waste time. The load function on your exam needs & on the vector parameter, otherwise it fills a copy that disappears.

3. Structs

A struct lets you bundle related variables into one custom type. Think of it as a recipe card with named slots.

Defining a struct

struct Book {
    string title;
    string author;
    int year;
};
The semicolon after the closing brace is required. Forget it and you'll get a wall of confusing compile errors. This is the #1 struct mistake.

Using a struct

Book b;
b.title = "Dune";
b.author = "Herbert";
b.year = 1965;

cout << b.title << " by " << b.author << endl;

The dot operator (.) gets you in and out of struct fields, both for reading and writing.

Passing structs to functions

void printBook(Book b) {
    cout << b.title << " (" << b.year << ")" << endl;
}

4. Vectors

A vector is a resizable array. You'll use it on every multi-part question on this exam.

The basics

#include <vector>

vector<int> nums;       // empty vector of ints
nums.push_back(10);     // add to end
nums.push_back(20);
nums.push_back(30);

cout << nums[0];        // prints 10
cout << nums.size();    // prints 3

Vectors of structs

Same thing, just put the struct name in the angle brackets.

vector<Trip> trips;
Trip t;
t.city = "Denver";
t.leave = 100;
t.back = 110;
trips.push_back(t);

Looping over a vector

for (int i = 0; i < nums.size(); i++) {
    cout << nums[i] << endl;
}

Pass by reference for vectors

Vectors can hold thousands of items. Copying them is slow. Always pass with & unless you have a good reason not to.

// Right way
void fillVec(vector<int>& v) {
    v.push_back(99);
}

// Wrong, the push_back happens to a local copy
void fillVec(vector<int> v) {
    v.push_back(99);
}
Returning vs reference: a function can either fill a vector via reference parameter (like load) OR build one locally and return it (like makeDays). Both are valid, the exam tests both styles.

5. Loops

For loops, while loops, and the all-important nested for loop pattern.

Standard for loop

for (int i = 0; i < 10; i++) {
    cout << i << endl;
}

Three parts: initialize (int i = 0), condition checked before each iteration (i < 10), update at end of each iteration (i++).

While loop

Use a while loop when you don't know the number of iterations up front.

int x = 2;
while (x < 100) {
    x = x * 2;
}
// x is now 128

Nested for loops, the every-pair pattern

Two loops, one inside the other. Used to compare every element to every other element. The trick is the inner loop starts at i + 1, not 0, so we don't compare an item to itself or check the same pair twice.

for (int i = 0; i < v.size(); i++) {
    for (int j = i + 1; j < v.size(); j++) {
        // compare v[i] to v[j] here
    }
}
Common bug: writing j = 0 instead of j = i + 1. This makes v[i] == v[j] always true when i == j, so any non-empty vector "has a match".

Looping with a state variable

Sometimes you need to remember something from a previous iteration. Declare the variable BEFORE the loop, update it inside.

int max = 0;
for (int i = 0; i < v.size(); i++) {
    if (v[i] > max) max = v[i];
}

6. Random Numbers

Two functions and two includes. Once you memorize the formula, this is easy points on the exam.

Setup

#include <cstdlib>   // rand, srand
#include <ctime>     // time

Seeding, do this once at the top of main

srand(time(0));

srand seeds the random number generator. time(0) returns the current time in seconds, so each run gets a different seed and different numbers.

Don't seed inside a loop or function that runs many times. If you do, repeated calls within the same second produce the same seed and identical sequences. Seed once, in main, before any rand calls.

The range formula

rand() % N           // 0 to N-1
rand() % N + 1       // 1 to N
rand() % 365 + 1     // 1 to 365 (a day of the year)
rand() % 6 + 1       // 1 to 6 (a die roll)

The pattern: rand() % range + start. The modulo gives you 0 up to range-1, then you shift up by start.

7. Type Casting & Probability Math

The most-missed concept on this style of exam. One little decimal point is the difference between 0 and 0.47.

Integer division, the trap

When both operands are integers, C++ throws away the decimal portion of the result.

int a = 5 / 2;          // a is 2, NOT 2.5
int b = 47 / 100;        // b is 0, NOT 0.47

The fix, force a double

Make at least one of the operands a double. Easiest way: write the literal with a .0.

double a = 5 / 2.0;       // 2.5, correct
double b = 47 / 100.0;     // 0.47, correct

You can also cast explicitly:

double b = (double)47 / 100;  // also 0.47
The exam will catch you with this. If count is an int and you write count / 100, the result is always 0 unless count is exactly 100 or higher. Always write count / 100.0 when computing a probability or percentage.

Probability pattern

int hits = 0;
for (int i = 0; i < 100; i++) {
    if (somethingHappened()) hits++;
}
double probability = hits / 100.0;

8. File I/O

The hardest part of this exam. Master this and the rest is downhill.

Open a file for reading

#include <fstream>

ifstream fin("data.txt");

That's it. fin is now connected to the file. You can read from it the same way you'd read from cin.

Two ways to read

The >> operator reads one whitespace-separated token at a time. Spaces, tabs, and newlines all count as whitespace.

int x;
string word;
fin >> x;       // reads next number
fin >> word;    // reads next word

getline reads up to a delimiter character. Default delimiter is newline.

string line;
getline(fin, line);              // read whole line
getline(fin, name, ',');        // read up to a comma

The mixed-reading problem

The exam gives you lines like Chicago, 45 55. The city name has spaces in it (think "New York"), so >> would only grab "New". You need getline with a comma delimiter for the city, then >> for the two numbers.

string city;
int a, b;
getline(fin, city, ',');  // "New York"
fin >> a >> b;            // 45 and 55
fin.ignore();             // throw away the newline
Why fin.ignore()? After reading the two ints with >>, the file position is sitting just before the newline. The next getline would read an empty string (because it stops at that newline immediately). fin.ignore() skips one character (the newline) so the next loop iteration starts on the next real line.

The full pattern in a loop

while (getline(fin, city, ',')) {
    fin >> a >> b;
    fin.ignore();
    // build struct, push_back
}

Putting getline in the while condition is clever: it keeps looping as long as the read succeeds, and stops automatically at end of file.

From Travis's exam, Part 2
Function load(string filename, vector<Trip>& trips). Each line is a city, comma, then two ints. Build a Trip and push to vector. 
void load(string filename, vector<Trip>& trips) {
    ifstream fin(filename);
    string city;
    int leave, back;
    while (getline(fin, city, ',')) {
        fin >> leave >> back;
        fin.ignore();
        Trip t;
        t.city = city;
        t.leave = leave;
        t.back = back;
        trips.push_back(t);
    }
}

Program 1, Hotel Reservations (Parts 1-5)

PART 1 Define a Reservation struct

Define a struct called Reservation that contains:
  • the guest's name
  • a number 1-365 for the check-in day
  • a number 1-365 for the check-out day
struct Reservation {
    string name;
    int checkIn;
    int checkOut;
};

PART 2 Function to read reservations from a file

Function name load. Parameters: filename and a vector of Reservations. Each line is: guest name, comma, then 2 numbers.

Example file bookings.txt:
Smith, 100 105
Garcia Lopez, 110 120
Chen, 118 125 
void load(string filename, vector<Reservation>& bookings) {
    ifstream fin(filename);
    string name;
    int in, out;
    while (getline(fin, name, ',')) {
        fin >> in >> out;
        fin.ignore();
        Reservation r;
        r.name = name;
        r.checkIn = in;
        r.checkOut = out;
        bookings.push_back(r);
    }
}

PART 3 Function to print one reservation

Function name print. Parameter: a Reservation. Print like "Smith 100-105". 
void print(Reservation r) {
    cout << r.name << " " << r.checkIn << "-" << r.checkOut << endl;
}

PART 4 Function to print non-overlapping bookings

Function name book. Parameter: vector of Reservations. Print bookings that don't overlap, skip ones whose check-in is on or before the previously printed booking's check-out. The reservations are already in order of check-in day.

Example output for the file above:
Smith 100-105
Garcia Lopez 110-120 
void book(vector<Reservation>& bookings) {
    int lastOut = 0;
    for (int i = 0; i < bookings.size(); i++) {
        if (bookings[i].checkIn > lastOut) {
            print(bookings[i]);
            lastOut = bookings[i].checkOut;
        }
    }
}

PART 5 Main program

Includes at top, call load with "bookings.txt", then call book. 
#include <iostream>

#include <vector>
#include <string>
using namespace std;

    vector<Reservation> bookings;
    load("bookings.txt", bookings);
    book(bookings);

}
Program 2, Lottery Number Probability (Parts 6-9)

In a lottery, you pick numbers from 1 to 50. We want to find out how big a group of pickers needs to be before two of them probably picked the same number.

PART 6 Function to generate random lottery picks

Function name pickNumbers. Parameter: group size (number of picks). Put that many random ints (1-50) into a vector. Return the vector. 
vector<int> pickNumbers(int size) {
    vector<int> picks;
    for (int i = 0; i < size; i++) {
        picks.push_back(rand() % 50 + 1);
    }
    return picks;
}

PART 7 Function to detect duplicates

Function name duplicate. Parameter: vector of ints. Compare every int to every other int. Return true if any two are the same, false otherwise. 
bool duplicate(vector<int> v) {
    for (int i = 0; i < v.size(); i++) {
        for (int j = i + 1; j < v.size(); j++) {
            if (v[i] == v[j]) return true;
        }
    }
    return false;
}

PART 8 Run 100 trials and return match rate

Function name trial. Parameter: group size. Call pickNumbers and duplicate 100 times. Count the duplicates. Probability is count / 100. Print group size and probability. Return the probability. 
double trial(int size) {
    int count = 0;
    for (int i = 0; i < 100; i++) {
        vector<int> picks = pickNumbers(size);
        if (duplicate(picks)) count++;
    }
    double prob = count / 100.0;
    cout << "size=" << size << " prob=" << prob << endl;
    return prob;
}

PART 9 Main, find smallest group with probable duplicate

Don't forget the includes. Call trial(2), trial(3), etc. in a loop. Stop when the return value is greater than 0.5. 
#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

// pickNumbers, duplicate, trial functions above

int main() {
    srand(time(0));
    int size = 2;
    while (trial(size) <= 0.5) {
        size++;
    }
    return 0;
}

Note: with a range of only 1-50 (vs 1-365 for birthdays), the threshold hits much faster. Travis should expect the loop to stop around size 8 or 9, not 23 like the birthday problem. Good place to ask him to predict the answer before running.
