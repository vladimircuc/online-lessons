Program 1, Daily Step Tracker (Parts 1-5)

A program that reads step-count logs from a file and prints only the days that set new step records.

PART 1

Define a struct called StepDay

Define a struct called StepDay that contains:
  • the user's name
  • a number 1-365 for the day of the year
  • an integer for the number of steps taken that day

Solution

struct StepDay {
    string user;
    int day;
    int steps;
};

Explanation

Three fields, one string and two ints. The semicolon after the closing brace is required, that is the most common bug. Field names should be descriptive so the rest of your code reads cleanly.
PART 2

Function to read step logs from a file

Function name load. Parameters: filename and a vector of StepDays. Each line is: user name, comma, then 2 numbers (day and steps). Build a StepDay for each line and add it to the vector.
Example steps.txt Alice, 12 6200
Bob, 13 8400
Alice, 15 7800
Carol, 18 9500
Bob, 20 9100
Alice, 22 11000

Solution

void load(string filename, vector<StepDay>& logs) {
    ifstream fin(filename);
    string user;
    int day, steps;
    while (getline(fin, user, ',')) {
        fin >> day >> steps;
        fin.ignore();  // skip the newline before next getline
        StepDay s;
        s.user = user;
        s.day = day;
        s.steps = steps;
        logs.push_back(s);
    }
}

Explanation

The vector parameter must have the & so we modify the original. getline(fin, user, ',') reads everything up to the comma into user. Then fin >> day >> steps grabs the two numbers (the leading space after the comma is automatically skipped by >>). fin.ignore() swallows the leftover newline so the next getline starts cleanly.
Common bug: Forgetting the & on the vector parameter, then wondering why the vector is empty back in main. The data went into a local copy that got thrown away.
PART 3

Function to print one step log

Function name print. One parameter: a StepDay. Print like "Alice day 12: 6200 steps".

Solution

void print(StepDay s) {
    cout << s.user << " day " << s.day << ": " << s.steps << " steps" << endl;
}

Explanation

Use the dot operator to access struct fields. Chain pieces with <<. Notice the spaces inside the literal strings so the words don't run into each other, like " day " (space, day, space) and ": " (colon, space).
PART 4

Function to print record-setting days

Function name records. Parameter: vector of StepDays. Print each log only if its step count is strictly greater than every step count we have already printed. The logs are already in date order.
Expected output for the example file Alice day 12: 6200 steps
Bob day 13: 8400 steps
Carol day 18: 9500 steps
Alice day 22: 11000 steps

Solution

void records(vector<StepDay>& logs) {
    int best = 0;
    for (int i = 0; i < logs.size(); i++) {
        if (logs[i].steps > best) {
            print(logs[i]);
            best = logs[i].steps;
        }
    }
}

Explanation

Track the highest step count we have seen so far in a variable called best. For each log entry, only print it if its steps beat the current best. After printing, update best to this new high. Initializing to 0 means the very first log always prints, since step counts are positive.
Watch the comparison: The problem says "strictly greater," so use >, not >=. A day that ties the current best doesn't count as a new record. (Bob day 20 with 9100 steps gets skipped because 9100 is less than the current best of 9500.)
PART 5

Main program

Put it all together. Includes at top, call load with "steps.txt", then call records.

Solution

#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

// struct StepDay { ... };
// void load(...) { ... }
// void print(...) { ... }
// void records(...) { ... }

int main() {
    vector<StepDay> logs;
    load("steps.txt", logs);
    records(logs);
    return 0;
}

Explanation

Four standard includes: iostream for cout, fstream for ifstream, vector and string for the data types. Declare an empty vector, fill it with load, print the record-setting days. return 0 at the end signals success.
Program 2, Lottery Pair Sum Coincidence (Parts 6-9)

A program to find out how big a lottery pool needs to be before two players' picks (each 1-50) probably sum to more than 80.

PART 6

Function to make random lottery picks

Function name makePicks. Parameter: pool size (number of picks to make). Put that many random ints (1-50) into a vector. Return the vector.

Solution

vector<int> makePicks(int size) {
    vector<int> picks;
    for (int i = 0; i < size; i++) {
        picks.push_back(rand() % 50 + 1);
    }
    return picks;
}

Explanation

rand() % 50 gives a number from 0 to 49. Adding 1 shifts it to 1-50. Loop size times, push each random number, return the vector.
Setup matters: srand(time(0)) must be called once in main, otherwise rand() gives the same sequence every run. Also need #include <cstdlib> for rand and #include <ctime> for time.
PART 7

Function to detect a big-sum pair

Function name bigSum. Parameter: vector of ints. Check every pair of numbers in the vector. Return true if any pair adds up to more than 80, false otherwise.

Solution

bool bigSum(vector<int> v) {
    for (int i = 0; i < v.size(); i++) {
        for (int j = i + 1; j < v.size(); j++) {
            if (v[i] + v[j] > 80) return true;
        }
    }
    return false;
}

Explanation

Same nested loop pattern as the duplicate-check problem, just with a different condition inside. The outer loop picks the first number, the inner loop picks every later number (starting at i + 1). For each pair, check if their sum is greater than 80. As soon as one qualifies, return true. If both loops finish without finding one, return false.
Don't write j = 0 in the inner loop. That would let j equal i, meaning we add a number to itself, which doubles it. A single number of 41+ would always trigger the check incorrectly.
PART 8

Function to run 100 trials and return the rate

Function name trial. Parameter: pool size. Call makePicks and bigSum 100 times. Count how many times bigSum returned true. Probability is count / 100. Print pool size and probability. Return the probability.

Solution

double trial(int size) {
    int count = 0;
    for (int i = 0; i < 100; i++) {
        vector<int> picks = makePicks(size);
        if (bigSum(picks)) count++;
    }
    double prob = count / 100.0;
    cout << "size=" << size << " prob=" << prob << endl;
    return prob;
}

Explanation

Loop 100 times. Each iteration: get a fresh random vector, check for a big-sum pair, increment count if found. Compute the probability as a double, print, return.
The classic trap: count / 100 is integer division, so 47 / 100 gives you 0, not 0.47. Use count / 100.0 with the .0 to force double division.
PART 9

Main program: find smallest pool with probable big sum

Don't forget the includes. Call trial(2), trial(3), etc. in a loop. Stop when the return value is greater than 0.5.

Solution

#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

// vector<int> makePicks(int size) { ... }
// bool bigSum(vector<int> v) { ... }
// double trial(int size) { ... }

int main() {
    srand(time(0));
    int size = 2;
    while (trial(size) <= 0.5) {
        size++;
    }
    return 0;
}

Explanation

srand(time(0)) seeds the random generator once at program start. The while loop calls trial(size), and as long as it returns 0.5 or less, we increment size and try again. As soon as trial returns more than 0.5, the loop exits. With this setup, the threshold typically hits around size 4 or 5, since each pick averages around 25 and only takes two slightly above-average picks to clear 80.
Don't put srand inside the loop. Seed once, at the top of main. Seeding repeatedly resets the sequence.
