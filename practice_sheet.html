PART 1

Define a struct called Trip

Define a struct called Trip that contains:
  • the name of a city
  • a number 1-365 for the proposed date to leave
  • a number 1-365 for the proposed date to return

Solution

struct Trip {
    string city;
    int leave;
    int back;
};

Explanation

A struct is a custom type that bundles related data. Three fields here, one string and two ints. Don't forget the semicolon after the closing brace, that's the most common mistake. Using string requires #include <string> at the top of the file.
PART 2

Function to read trips from a file

Function name load. Parameters: filename and a vector of Trips. Each line is a trip: city followed by a comma, then 2 numbers. Store each as a Trip in the vector.

Solution

void load(string filename, vector<Trip>& trips) {
    ifstream fin(filename);
    string city;
    int leave, back;
    while (getline(fin, city, ',')) {
        fin >> leave >> back;
        fin.ignore();  // skip the newline before next getline
        Trip t;
        t.city = city;
        t.leave = leave;
        t.back = back;
        trips.push_back(t);
    }
}

Explanation

The vector parameter MUST be passed by reference with the &, otherwise we'd be filling a local copy that gets discarded. getline(fin, city, ',') reads everything up to the comma into city. Then fin >> leave >> back reads the two ints (whitespace-separated, including the leading space after the comma is skipped automatically by >>). The fin.ignore() swallows the leftover newline so the next getline starts cleanly.
Common bug: Forgetting the & on the vector parameter. Code compiles, runs, but no trips appear because they're added to a copy.
PART 3

Function to print one trip

Function name print. One parameter: a Trip. Print like "Los Angeles 34-38".

Solution

void print(Trip t) {
    cout << t.city << " " << t.leave << "-" << t.back << endl;
}

Explanation

Access struct fields with the dot operator. Output is space, then numbers separated by a hyphen. void because we print but return nothing. Could also pass by const reference (const Trip& t) for efficiency, but plain by-value is acceptable since a Trip is small.
PART 4

Function to print non-overlapping trips

Function name skej. Parameter: vector of Trips. Skip trips that start on or before the day you come back from the previously printed trip. Trips are already sorted by start day.

Solution

void skej(vector<Trip>& trips) {
    int lastReturn = 0;
    for (int i = 0; i < trips.size(); i++) {
        if (trips[i].leave > lastReturn) {
            print(trips[i]);
            lastReturn = trips[i].back;
        }
    }
}

Explanation

Track the return day of the last trip we printed. For each trip, only print it if its start day is strictly greater than that. After printing, update lastReturn. Initializing to 0 means the very first trip always prints (since all leave days are 1 or higher).
Watch the comparison: The problem says skip trips that start "before or on" the previous return. So we print only when leave > lastReturn, not >=.
PART 5

Main program

Put it all together. Includes at top, call load with "travel.txt", then call skej.

Solution

#include <iostream>
#include <fstream>
#include <vector>
#include <string>
using namespace std;

// struct Trip { ... };
// void load(...) { ... }
// void print(...) { ... }
// void skej(...) { ... }

int main() {
    vector<Trip> trips;
    load("travel.txt", trips);
    skej(trips);
    return 0;
}

Explanation

Four standard includes cover everything: iostream for cout, fstream for ifstream, vector and string for the data types. Declare the vector empty, load fills it, skej prints from it.
PART 6

Function to make random birthdays

Function name makeDays. Parameter: group size. Put that many random ints (1-365) into a vector. Return the vector.

Solution

vector<int> makeDays(int size) {
    vector<int> days;
    for (int i = 0; i < size; i++) {
        days.push_back(rand() % 365 + 1);
    }
    return days;
}

Explanation

rand() % 365 gives a number from 0 to 364. Adding 1 shifts to 1-365 as required. Loop size times, push each random number, return the vector.
Setup matters: srand(time(0)) must be called once in main, otherwise rand() gives the same sequence every run. Also need #include <cstdlib> for rand and #include <ctime> for time.
PART 7

Function to find duplicates

Function name match. Parameter: vector of ints. Compare every int to every other int. Return true if any two are the same, false otherwise.

Solution

bool match(vector<int> v) {
    for (int i = 0; i < v.size(); i++) {
        for (int j = i + 1; j < v.size(); j++) {
            if (v[i] == v[j]) return true;
        }
    }
    return false;
}

Explanation

Classic nested loop pattern for comparing every pair. Outer loop picks the first item, inner loop checks every later item. Starting j = i + 1 avoids comparing an item to itself and avoids checking the same pair twice. The moment we find a match, return true and exit. If we finish both loops without finding one, return false.
Don't write j = 0 in the inner loop, that compares every element to itself and gives a false positive on every call.
PART 8

Function to run 100 trials and return average match rate

Function name trial. Parameter: group size. Run makeDays + match 100 times. Count matches. Probability is count / 100. Print group size and probability. Return the probability.

Solution

double trial(int size) {
    int count = 0;
    for (int i = 0; i < 100; i++) {
        vector<int> days = makeDays(size);
        if (match(days)) count++;
    }
    double prob = count / 100.0;
    cout << "size=" << size << " prob=" << prob << endl;
    return prob;
}

Explanation

Loop 100 times. Each iteration: get a fresh random vector, check for a match, increment count if found. Compute probability as a double, print, return.
The biggest gotcha on this whole exam: count / 100 is integer division. If count is 47, you get 0, not 0.47. Use count / 100.0 (note the .0) to force double division. This is the question that catches almost every student.
PART 9

Main program: find smallest group with probable match

Call trial(2), trial(3), etc. in a loop. Stop when the return value is greater than 0.5.

Solution

#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
using namespace std;

// vector<int> makeDays(int size) { ... }
// bool match(vector<int> v) { ... }
// double trial(int size) { ... }

int main() {
    srand(time(0));
    int size = 2;
    while (trial(size) <= 0.5) {
        size++;
    }
    return 0;
}

Explanation

srand(time(0)) seeds the random generator once at program start. The while loop calls trial(size), and as long as it returns 0.5 or less, we increment size and try again. As soon as trial returns more than 0.5, the loop exits. The final printed line is the smallest group size where match probability exceeds 50%.
Don't put srand inside the loop. Seed once, at the top of main. Seeding repeatedly with the same time value resets the sequence.
